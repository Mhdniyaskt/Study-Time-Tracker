# Study Time Tracker

A simple desktop application for tracking study time.

---

## Download for Windows

Download the latest version:

👉 **[Download Study Time Tracker for Windows](https://github.com/Mhdniyaskt/Study-Time-Tracker/releases/latest)**

---

## Installation

1. Open the latest GitHub Release using the link above.
2. Download `Study Time Tracker Setup.exe`.
3. Run the installer.
4. Follow the installation instructions.
5. Launch Study Time Tracker.

No additional software is required.

---

## Requirements

Windows 10 or newer.

No:
- Node.js
- npm
- MongoDB
- Git
- Python
- VS Code

are required.

The application uses its embedded local database.

---

## Features

- **Free Study Timer** — Track flexible study sessions with real-time controls (play, pause, resume, stop & save).
- **Focus / Pomodoro Mode** — Structured intervals with custom focus duration, break periods, and round counts.
- **Daily Goals & Streaks** — Set daily study targets and maintain your productive streak.
- **Study History & Analytics** — Review past study sessions with date filters, subject breakdowns, and visual charts.
- **Floating Timer Widget** — Convenient, compact floating mini-timer that stays on top of your windows.
- **System Tray Controls** — Quick controls directly from the Windows taskbar and system tray.
- **Desktop Notifications** — Native Windows alerts when focus sessions or breaks complete.
- **Offline Embedded Database** — Fast, private local database stored entirely on your computer.
- **Automatic Updates** — Built-in auto-update system with one-click installation.

---

## Data Storage

Study data is stored locally on the user's computer.

All study sessions, statistics, goals, and preferences are saved directly to your machine. No external database, account creation, or cloud service is required.

Application data is preserved across application updates.

---

## Automatic Updates

Study Time Tracker automatically checks for new versions.

When an update is available:
1. The application notifies the user.
2. User chooses **Download Update**.
3. The update downloads in the background.
4. User chooses **Restart & Install**.
5. The application updates.

Existing study data remains intact throughout all updates.

You can also manually check for updates at any time:
- Navigate to: **Settings → System/About → Check for Updates**
